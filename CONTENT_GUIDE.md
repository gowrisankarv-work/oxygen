# Content guide — how to update the website

This guide is for anyone updating the site’s text, images or settings. You only need a text
editor. After editing, run `npm run dev` to preview, then `npm run build` (or push to your host)
to publish.

> Tip: run `npm run check:placeholders` at any time to see every sample value that still needs
> real data, with the exact file and line.

## Rules that keep the site honest

- Never present invented achievements, rankings, accreditations, partnerships or figures as real.
- Testimonials must be genuine and used with written consent; keep `isSample: true` until then.
- Do not write copy that guarantees admission, jobs or publication.
- Publication copy must keep the ethics commitments (no ghostwriting, no authorship sales, no predatory journals).
