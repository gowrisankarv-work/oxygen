# Client handover checklist

Everything below must be supplied or confirmed before the site goes live. Each item lists the
exact file/field to update (details in **CONTENT_GUIDE.md**). When finished,
`npm run check:placeholders -- --strict` should report nothing.

| ✔   | Item                                                                                                                              | Where it goes                                                                                                                                        |
| --- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| ☐   | **Real contact details** — phone, WhatsApp number, email(s)                                                                       | `src/config/site.config.ts` → `contact.phone`, `contact.phoneDisplay`, `contact.whatsapp`, `contact.email`, `contact.altEmail`                       |
| ☐   | **Office address**                                                                                                                | `site.config.ts` → `contact.address.*`                                                                                                               |
| ☐   | **Google Maps embed URL and directions link**                                                                                     | `site.config.ts` → `contact.mapEmbedUrl`, `contact.mapLink`                                                                                          |
| ☐   | **Business hours**                                                                                                                | `site.config.ts` → `contact.hours[]`                                                                                                                 |
| ☐   | **Response-time promise you can keep**                                                                                            | `site.config.ts` → `contact.responseTime`; `src/content/process.ts` → `turnaround`                                                                   |
| ☐   | **Final logo files** (SVG preferred) + confirmation of logo ownership / trademark rights                                          | `public/brand/logo-full.svg`, `logo-wordmark-white.svg`, `emblem.svg`; set `brand.logoSource: 'files'`; run `npm run og`                             |
| ☐   | **Founder details and photo**                                                                                                     | `site.config.ts` → `people.founder` (`name`, `title`, `photo`, `message`)                                                                            |
| ☐   | **Team details and photos** (or hide the section)                                                                                 | `src/content/team.ts` (`isSample: false`) or `features.showTeam: false`                                                                              |
| ☐   | **Grievance officer / contact person** (named in the Privacy Policy)                                                              | `site.config.ts` → `people.contactPerson`                                                                                                            |
| ☐   | **Genuine testimonials with written consent** (or hide the section)                                                               | `src/content/testimonials.ts` (`isSample: false`) or `features.showTestimonials: false`                                                              |
| ☐   | **Verified statistics** (optional)                                                                                                | `src/content/stats.ts` (`isSample: false`) + `features.showStats: true`                                                                              |
| ☐   | **Confirm actual service scope** for each of the four services (incl. whether study-abroad visa guidance is offered)              | `src/content/services.ts`; `features.showStudyAbroadVisa`                                                                                            |
| ☐   | **Pricing policy** (publish or keep “shared after consultation”)                                                                  | `features.showPricing`                                                                                                                               |

| ☐   | **Social media URLs**                                                                                                             | `site.config.ts` → `social.*` (empty hides the icon)                                                                                                 |
| ☐   | **Twitter/X handle** (optional)                                                                                                   | `site.config.ts` → `seo.twitterHandle`                                                                                                               |
| ☐   | **City for local SEO copy**                                                                                                       | `site.config.ts` → `seo.keywordsCity`                                                                                                                |
| ☐   | **Domain name**                                                                                                                   | Host dashboard + `VITE_SITE_URL` env variable                                                                                                        |
| ☐   | **Form provider account** (Web3Forms or Formspree) and access key / endpoint                                                      | Host env: `VITE_FORM_PROVIDER`, `VITE_FORM_ACCESS_KEY` / `VITE_FORM_ENDPOINT`                                                                        |

| ☐   | **Named article authors** (optional)                                                                                              | `src/content/articles/index.ts` → `author`                                                                                                           |

## Before launch

1. `npm run check:placeholders -- --strict` passes.
2. `npm run verify` passes (typecheck, lint, format, unit, build, E2E).
3. Deploy; run Lighthouse (mobile) on the home page, a service page and an article.
4. Submit `sitemap.xml` in Google Search Console; test one page in the Rich Results Test.
5. Send a test enquiry through each form and confirm it arrives.
